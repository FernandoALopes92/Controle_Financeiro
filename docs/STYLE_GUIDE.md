# 🎨 Guia de Estilo – App de Gestão Financeira

Este guia define a paleta de cores, os estilos de botões e componentes básicos para manter o visual consistente, moderno e vibrante.

---

## 🌈 Paleta de Cores

| Finalidade        | Cor                | Hex       | Observações                                      |
|-------------------|--------------------|-----------|--------------------------------------------------|
| Ação primária     | Roxo vibrante       | `#8e2de2` | Cor principal da marca, usada no navbar          |
| Edição            | Lavanda claro       | `#b892f6` | Suave e amigável, bom para ações de edição       |
| Exclusão          | Rosa púrpura forte  | `#d04ed6` | Vibrante, chama atenção sem ser "vermelho"       |
| Confirmação       | Roxo azulado médio  | `#7f65f2` | Alternativa ao verde, mantém o estilo            |
| Alerta/aviso      | Lilás vibrante      | `#c17fff` | Usado para alertas com leveza visual             |
| Fundo escuro      | Roxo profundo       | `#3b0a87` | Ótimo para rodapés, painéis, modais              |
| Texto claro       | Branco suave        | `#fefefe` | Contraste para fundos escuros e botões roxos     |
